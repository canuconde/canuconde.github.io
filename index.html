Proyectos

Sigma Contable

Aplicación de escritorio para gestión contable desarrollada en C++ utilizando SQLite y wxWidgets.

Características:

  • almacenamiento local con SQLite
  • interfaz nativa de escritorio
  • gestión de registros contables
  • soporte para temas
  • diseño liviano y rápido

Tecnologías: C++ SQLite3 wxWidgets

Repositorio en GitHub

EQ-for-MOC

Ecualizador para Music On Console desarrollado en C++ con ncurses.

Características:

  • interfaz en terminal
  • presets persistentes
  • edición de perfiles
  • soporte para temas de colores
  • aplicación rápida y liviana

Tecnologías: C++ ncurses Linux

Repositorio en GitHub
