MemoriaForge: IA local en C++ sin complicaciones

20-jun-2026 486 palabras 3 minutos

Un wrapper ligero de llama.cpp para crear aplicaciones con IA local en pocas líneas de código.

Crear aplicaciones con IA local en C++ nunca fue tan fácil

Los modelos de lenguaje ya no son exclusivos de Python.

Gracias a llama.cpp es posible ejecutar modelos GGUF de forma local en prácticamente cualquier equipo. Sin embargo, integrar llama.cpp directamente en un proyecto suele implicar manejar contexto, historial de conversación, persistencia de estado y parámetros de generación.

MemoriaForge elimina esa complejidad.

Su objetivo es ofrecer una API simple para que puedas concentrarte en desarrollar tu aplicación y no en los detalles internos de la inferencia.

¿Qué es MemoriaForge?

MemoriaForge es una biblioteca C++ construida sobre llama.cpp que permite integrar modelos GGUF mediante una interfaz sencilla y moderna.

Con unas pocas líneas de código puedes:

  • Cargar modelos GGUF
  • Mantener conversaciones con memoria
  • Inyectar contexto personalizado
  • Guardar y restaurar sesiones completas
  • Configurar parámetros de generación
  • Obtener respuestas de modelos locales

Todo sin interactuar directamente con la API de bajo nivel de llama.cpp.

Instalación

La forma más sencilla es utilizar las bibliotecas precompiladas disponibles en la sección de Releases.

Descarga el paquete correspondiente a tu sistema operativo y agrega:

libMemoriaForge.so

o en Windows:

MemoriaForge.dll
libMemoriaForge.a

a tu proyecto.

Luego enlaza la biblioteca como cualquier dependencia C++.

Tu primer programa

#include <iostream>
#include "MemoriaForge.h"

int main() {

    MemoriaForge::LLMSession llm("models/Qwen3-0.6B-Q4_K_M.gguf");

    std::cout <<llm.chat("¿Qué es una red neuronal?")<< std::endl;

    return 0;
}

Eso es todo.

Ya tienes una aplicación capaz de interactuar con un modelo de lenguaje ejecutándose localmente.

Si quieres compilarlo desde linea de comandos:

c++ main.cpp -iMemoriaForge -o ChatSimple

Memoria persistente

Una de las características principales de MemoriaForge es la posibilidad de guardar y restaurar el estado completo de una conversación.

Guardar:

llm.save_state("chat.bin");

Restaurar:

llm.load_state("chat.bin");

Esto permite continuar una conversación incluso después de cerrar la aplicación.

Además evita tener que reconstruir manualmente el contexto en cada ejecución.

Inyectar conocimiento

Puedes agregar información adicional al contexto del modelo antes de comenzar a generar respuestas.

llm.context_injector(
    "Eres un asistente especializado en Linux."
);

o cargar información desde archivos:

llm.context_injector(documento);

Ideal para:

  • Asistentes personales
  • Sistemas de documentación
  • Herramientas educativas
  • Software empresarial
  • NPCs para videojuegos

Configurar la generación

Los parámetros de muestreo pueden modificarse dinámicamente.

llm.set_sampling_params(
    0.2f,  // min_p
    0.8f,  // temperatura
    42     // seed
);

Esto permite ajustar el equilibrio entre creatividad, precisión y reproducibilidad.

¿Por qué usar MemoriaForge?

Porque te permite aprovechar toda la potencia de llama.cpp sin trabajar directamente con su API.

Menos código

MemoriaForge::LLMSession llm(modelo);

std::string respuesta =llm.chat("Hola");

Persistencia integrada

API simple

MemoriaForge te proporciona una API simple, persistencia de contexto y bibliotecas listas para usar para que puedas comenzar a desarrollar en minutos.
