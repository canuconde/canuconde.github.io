EQ4MOC

Equalizador visual para Music On Console hecho en C++ y ncurses

Repositorio oficial de EQ4MOC

Dale nueva vida a Music On Console

EQ4MOC es una aplicación para Linux desarrollada en C++ que permite editar ecualizadores de Music On Console (MOC) desde una interfaz visual en terminal utilizando ncurses.

En lugar de modificar archivos de configuración manualmente, EQ4MOC ofrece una experiencia rápida, cómoda y completamente integrada con el ecosistema clásico de Linux.

El proyecto fue compartido originalmente en Reddit como una solución para quienes usan MOC diariamente y querían evitar editar presets “a mano”.

✨ Características

  • 🎚️ Interfaz visual en terminal
  • ⚡ Desarrollo nativo en C++
  • 🖥️ Compatible con entornos minimalistas
  • 🎨 Integración con el tema configurado en MOC
  • 📂 Carga automática de archivos EQSET
  • 🔧 Creación automática de configuración por defecto
  • ⌨️ Pensado para usuarios de teclado y terminal
  • 🐧 Ideal para Linux clásico y workflows retro/minimalistas

🧠 Filosofía del proyecto

EQ4MOC está pensado para quienes disfrutan:

  • herramientas livianas,
  • software que hace una sola cosa bien,
  • aplicaciones en terminal rápidas y eficientes,
  • y el estilo clásico UNIX.

No intenta reemplazar interfaces modernas pesadas. Busca ofrecer una experiencia directa, veloz y funcional.

🖼️ Una interfaz simple y efectiva

El proyecto utiliza ncurses para construir una interfaz totalmente navegable desde teclado, manteniendo el espíritu de las aplicaciones Linux de principios de los 2000.

Perfecto para:

  • usuarios de tiling window managers,
  • amantes de terminales retro,
  • servidores personales,
  • PCs antiguas,
  • y setups minimalistas.

⚙️ Tecnologías utilizadas

  • C++
  • ncurses
  • Linux
  • Music On Console (MOC)

🚀 Instalación

git clone https://github.com/canuconde/EQ4MOC.git
cd EQ4MOC
make
make install
./eq4moc

También podés descargar los binarios:

  • eq4moc_1.1.1-1_amd64.deb

  • eq4moc_1.0-1_i386.deb

🎵 ¿Qué es Music On Console?

Music On Console es uno de los reproductores de música en terminal más queridos dentro del ecosistema Linux.

EQ4MOC nace como una extensión natural para mejorar la experiencia de uso de MOC sin abandonar la terminal.

💡 ¿Por qué usar EQ4MOC?

Porque editar archivos de ecualización manualmente:

  • es lento,
  • incómodo,
  • propenso a errores,
  • y rompe el flujo de trabajo.

EQ4MOC transforma esa tarea en algo visual, rápido y agradable.

📸 Ideal para amantes de:

  • Linux clásico
  • aplicaciones TUI
  • ncurses
  • herramientas minimalistas
  • audio en terminal
  • workflows keyboard-driven
